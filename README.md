# По полочкам

Приложение для iPhone, которое раскладывает фото по категориям прямо на телефоне. Для каждого фото оно определяет, что на нём изображено, читает текст на снимке и предлагает имя вида «2026-07-23 Пятигорск, Белка». Внутри категорий фото идут от новых к старым. Готовую раскладку можно одной кнопкой превратить в альбомы в приложении «Фото».

## Как это устроено

- **Что на фото и какая категория.** Модель OpenCLIP ViT-B-32 (веса LAION-2B, лицензия MIT) переведена в Core ML и работает на телефоне. Тексты 23 категорий и 188 подписей закодированы заранее, поэтому в приложение попадает только кодировщик изображений.
- **Скриншоты** определяются по признаку из PhotoKit, модель для них не нужна.
- **Текст на фото** читает встроенное распознавание Apple (русский и английский).
- **Город** берётся по координатам фото через Apple Maps. Сами фото никуда не отправляются.
- **Результаты** кешируются на телефоне, повторно фото не разбираются.

Категории и подписи лежат в `PhotoSorter/Resources/taxonomy.json`. После правки этого файла CI сам пересоберёт эмбеддинги.

## Сборка

Своего Mac у проекта нет, всё собирает GitHub Actions (`.github/workflows/ios.yml`):

1. `ml/export_models.py` скачивает веса, переводит модель в `PhotoSorter/Generated/ImageEncoder.mlpackage` и сохраняет эмбеддинги категорий и подписей. Результат кешируется.
2. XcodeGen создаёт проект из `project.yml`.
3. `xcodebuild test` на каждый PR собирает приложение и на симуляторе сверяет модель в Core ML с исходной в PyTorch (`PhotoSorterTests`).

4. Отдельная задача собирает `PhotoSorter.ipa` без подписи и кладёт его в артефакты сборки вместе с `source.json` для SideStore (его делает `sidestore/make_source.py`). В Releases сборка попадает, только если запустить Actions, iOS, Run workflow с галочкой «Выложить .ipa и источник SideStore в Releases».

Сборка в TestFlight запускается вручную: Actions, iOS, Run workflow, галочка «Отправить сборку в TestFlight». Для неё нужны секреты репозитория `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` и `APPLE_TEAM_ID`.

## Установка через SideStore

Платный аккаунт Apple для этого не нужен: SideStore подписывает приложение обычным Apple ID.

Для проверки на своём телефоне: откройте нужную сборку в Actions, скачайте артефакт `PhotoSorter-ipa`, распакуйте его в «Файлах» и выберите `PhotoSorter.ipa` в SideStore (My Apps, «+»).

Если сборку выложить в Releases, её можно ставить и обновлять через источник (Sources, «+»):

```
https://github.com/aleshadorokhov-cyber/photo_sorter/releases/latest/download/source.json
```

Подпись бесплатного Apple ID действует 7 дней, её продлевает «Refresh All» в SideStore.

## Структура

```
PhotoSorter/
  App/        точка входа
  Model/      разбор галереи, кеш, альбомы, имена
  ML/         CLIP через Core ML и распознавание текста
  Views/      экраны SwiftUI
  Resources/  taxonomy.json, иконка
PhotoSorterTests/  проверка модели на симуляторе
ml/           подготовка модели для iPhone
sidestore/    источник для SideStore
project.yml   описание проекта для XcodeGen
```
