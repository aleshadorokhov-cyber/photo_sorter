# Бесплатная установка на iPhone

Проверено по официальным инструкциям 9 ноября 2026 года. Приложение рассчитано на iOS 17 и новее. Платная подписка Apple Developer не требуется для варианта с SideStore.

## Выбранный вариант: GitHub Actions + SideStore

Сборка выполняется на облачном Mac GitHub Actions. Стандартные раннеры бесплатны для этого уже публичного репозитория. Фото пользователя и его ключи в репозиторий не добавляются. Это не делает исходники приватными: репозиторий уже открыт. Приватность отдельного веб-приложения от этого не меняется.

Результат — PhotoSorter.ipa БЕЗ подписи. Это не файл для установки одним нажатием в Safari: SideStore подписывает его собственным бесплатным Apple Account пользователя. Пароль не нужно сообщать автору приложения или помощнику.

### Что потребуется

- iPhone с кодом блокировки, Wi-Fi и собственный Apple Account.
- Компьютер Windows, Mac или Linux и USB-кабель для начальной установки SideStore. Mac покупать или арендовать не нужно. После первоначальной настройки продление обычно выполняется на самом iPhone. После некоторых обновлений или сбросов повторное подключение к компьютеру может понадобиться.
- Бесплатные iloader на компьютере и LocalDevVPN на iPhone, установленные по ссылкам из официальной документации SideStore.

### Первоначальная настройка

1. Откройте [официальную подготовку SideStore](https://docs.sidestore.io/docs/installation/prerequisites). Для Windows установите iTunes и iloader по приведённым там ссылкам. Установите LocalDevVPN на iPhone.
2. Подключите iPhone по USB, подтвердите доверие компьютеру. В iloader войдите в собственный Apple Account, выберите телефон и Install SideStore (Stable).
3. Следуйте [официальной инструкции для вашей версии iOS](https://docs.sidestore.io/docs/installation/install). Для iOS 18+: Настройки → Основные → VPN и управление устройством → профиль с вашим Apple Account → Allow & Restart. Затем Настройки → Конфиденциальность и безопасность → Режим разработчика.
4. Подключитесь к Wi-Fi. Включите LocalDevVPN, откройте SideStore, войдите в тот же Apple Account. В My Apps нажмите счётчик срока подписи SideStore для первого продления.
5. Скачайте артефакт PhotoSorter-ipa из успешной сборки GitHub Actions и распакуйте ZIP в «Файлах». В SideStore → My Apps → «+» выберите PhotoSorter.ipa. Дождитесь подписи и установки.
6. Откройте «По полочкам», разрешите доступ ко всем фото или только выбранным, затем нажмите «Проверить фото». Начните с небольшого набора копий тестовых снимков.

Подпись бесплатного аккаунта действует 7 дней. До её истечения используйте Refresh All в SideStore через Wi-Fi с включённым LocalDevVPN. Сначала проверьте ручное продление; не полагайтесь на фоновое продление, пока не убедитесь, что оно работает на вашем телефоне. При истёкшей подписи приложение перестаёт запускаться до переподписи.

Для бесплатного Apple Account действует лимит в три активных приложения, включая сам SideStore. LocalDevVPN, установленный через App Store, не занимает этот слот. SideStore и «По полочкам» занимают два слота.

Наличие source.json в артефакте не означает, что файл опубликован по указанному в нём release URL. Публикация в Releases отключена по умолчанию; для установки из артефакта используйте сам IPA.

## Другие варианты

| Вариант | Плата | Компьютер и аккаунт | Ограничение |
| --- | --- | --- | --- |
| SideStore | Платная подписка Apple не нужна | Компьютер первоначально, собственный Apple Account | Переподпись каждые 7 дней, Wi-Fi и LocalDevVPN |
| AltStore Classic | Базовая установка бесплатна | Компьютер с AltServer и Apple Account | Для регулярного продления нужен доступ к AltServer |
| Xcode Personal Team | Xcode и личное тестирование бесплатны | Mac и собственный Apple Account | Ограниченная подпись; облачный Mac сам по себе не подключается к USB iPhone |
| Веб-приложение Safari | Может быть бесплатным | Mac и подпись не нужны | Анализирует только выбранные файлы и не удаляет оригиналы из медиатеки |
| TestFlight | Пользователь устанавливает бесплатно | Разработчику обычно нужен платный Apple Developer Program | Не соответствует полностью бесплатной самостоятельной публикации |

Бесплатную стабильную установку собственного нативного приложения одновременно без компьютера, без любого Apple Account и без подписи подтвердить не удалось. Аренда чужого Apple Account эту задачу не решает. Для iOS 18 TrollStore не подходит по официальному списку совместимости.

## Проверка на реальном телефоне после установки

1. Разрешить только 5–10 тестовых фото. Проверить, что остальные не видны.
2. Добавить две копии одного исходного файла, одно избранное, снимок до 2020 года и фото без даты. Проверить группы и защиту избранного.
3. Открыть выбранные фото, отменить подтверждение удаления: ничего не должно исчезнуть.
4. Удалить только одну тестовую копию и проверить «Недавно удалённые» в «Фото».
5. Изменить избранное/медиатеку во время проверки и убедиться, что требуется новая проверка.
6. Проверить фото из iCloud при выключенной и включённой загрузке. Пропуски должны быть видны, а не считаться отсутствием дублей.
7. Выполнить пробное продление подписи SideStore до истечения 7 дней.

Автотесты не заменяют эти проверки на физическом iPhone; приложение не получает удалённого доступа к устройству пользователя.
