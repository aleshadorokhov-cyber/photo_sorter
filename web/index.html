По полочкам

Фото разбираются прямо на телефоне и никуда не отправляются.

Выберите фото, и приложение разложит их по категориям: внутри от новых к старым, с именем вида «2026-07-23 Пятигорск, Белка». Текст на фото оно прочитает и определит его тему.

Как выбрать сразу весь альбом

Названия кнопок даны как на iPhone с английским языком.

Весь альбом сразу.

  1. В «Фото» откройте альбом или Recents, нажмите Select, затем Select All.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой), затем Save to Files, выберите или создайте папку и нажмите Save.
  3. Здесь нажмите «Выбрать фото», затем Choose Files, откройте эту папку, нажмите Select, затем Select All и Open.

Через окно выбора. Нажмите «Выбрать фото», затем Photo Library, откройте Albums и нужный альбом. Кнопки Select All там нет, но можно провести пальцем по миниатюрам, не отрывая его: отметятся все, по которым он прошёл.

Те же фото второй раз не добавятся, так что альбом можно докладывать частями.

Альбомы в «Фото». Команда на iPhone создаст по альбому «Сортировка: …» на каждую категорию и добавит в него эти же снимки из вашей галереи, без копий. Перед первым разом один раз поставьте команды и проверьте их на одном снимке. Запускайте команды только этой кнопкой: из приложения Shortcuts они возьмут то, что лежит в буфере обмена.

Установить «По полочкам» Установить «По полочкам добавить» Установить «По полочкам убрать»

Откроется Shortcuts: нажмите Add Shortcut, затем вернитесь сюда за следующей. Не переименовывайте команды: сайт запускает их по имени. Если такие команды у вас уже есть, сначала удалите старые, иначе новые получат имя с цифрой. При первом запуске iPhone спросит доступ к буферу обмена и к «Фото»: нажмите Allow, а для «Фото» выберите полный доступ.

Галочка: альбом уже есть в «Фото», новые снимки лягут в него, второй такой же не появится. Без галочки альбом будет создан. Сайт ставит галочки сам после создания; если альбомы уже были, отметьте их.

Если впишете название альбома точно как в «Фото», после раскладки снимки уберутся из него третьей командой «По полочкам убрать». Из «Фото» они не удаляются и остаются в альбомах «Сортировка: …» и в Recents. Оставьте пустым, если брали из Recents или хотите, чтобы снимки остались и в старом альбоме.

Как один раз настроить команду

Названия даны как на iPhone с английским языком. Займёт минут десять, потом команда просто запускается этой кнопкой.

Открыть новую команду в Shortcuts

Или сами: приложение Shortcuts, вкладка Library, «+» справа вверху.

Как работать в редакторе

  • Добавить действие. Внизу экрана поле Search Actions. Нажмите его, введите слово из шага ниже и нажмите в списке действие с точно таким названием, как жирное в шаге. Оно добавится в команду и дальше читается уже фразой, например Get Dictionary from Input становится «Get dictionary from Clipboard».
  • Переставить. Новое действие всегда встаёт в самый низ. Зажмите его за название и, не отпуская, тяните вверх на нужное место. Всё, что внутри повтора, сдвинуто вправо.
  • Синие слова в действии можно менять. Нажмите синее слово: появится список или строка над клавиатурой с вариантами вроде Repeat Item. Нажмите нужный. Если его там нет, нажмите Select Variable и найдите его там.
  • Ошиблись с синим словом: нажмите его ещё раз и выберите заново.

Важно: Repeat Item, Repeat Item 2, Repeat Results, Dictionary, Dictionary Value и Clipboard нужно выбирать из списка, а не печатать буквами. Выбранное выглядит как плашка со значком: у Repeat Item и Repeat Results это серые стрелки повтора, у Dictionary оранжевая книжка. Если слова просто напечатаны, без значка, команда создаст пустой альбом с именем «Repeat Item». Тогда нажмите это поле, сотрите текст и выберите вариант в строке над клавиатурой или через Select Variable.

Имя команды

Нажмите New Shortcut вверху по центру, затем Rename, введите По полочкам и нажмите Done на клавиатуре.

Если команда уже собрана по прежним шагам и альбом получается с названием из скобок: в прежних шагах не хватало одного действия.

  1. Добавьте Get Dictionary Value (поиск get dictionary) и перетащите его сразу под «Get dictionary from Clipboard», выше первого «Repeat with each…».
  2. В нём нажмите синее слово Value и выберите All Keys. Если последнее синее слово не Dictionary, нажмите его и выберите Dictionary с оранжевой книжкой. Должно читаться «Get All Keys in Dictionary».
  3. В первом «Repeat with each item in» нажмите Dictionary и выберите Dictionary Value.

Если альбом назван верно, но пустой, почти всегда где-то напечатано слово вместо выбранной переменной:

  1. В «Get Value for Repeat Item in Dictionary» у Repeat Item должен быть значок серых стрелок. Если значка нет, нажмите Repeat Item, сотрите текст и выберите Repeat Item в строке над клавиатурой. Если его там нет, нажмите Select Variable и коснитесь верхнего «Repeat with each item in Dictionary Value».
  2. В «Find Photos where Name begins with Repeat Item 2» то же самое: нужен значок стрелок. Без значка сотрите и выберите Repeat Item 2, через Select Variable это второй, нижний «Repeat with each…».
  3. В Find Photos должно стоять begins with, а не is. Если при запуске iPhone спросит доступ к фото, разрешите.
  4. Действие должно начинаться словами Find Photos where. Если оно читается «Filter … where», оно ищет не во всей медиатеке, а в том, что пришло из действия над ним, и ничего не найдёт. Нажмите плашку сразу после Filter (обычно Repeat Item 2) и выберите Clear. Удалять действие и добавлять заново не помогает: Shortcuts снова подставит Repeat Item 2. Признак этой ошибки: вместо снимка в альбом и в «Фото» попадает белая картинка с именем снимка; её можно удалить.
  5. Между вторым «Repeat with each…» и Find Photos не должно быть других действий. Лишнее удалите крестиком справа.

Остальное не трогайте и снова нажмите проверку на одном снимке.

Восемь действий по порядку

  1. Get Clipboard Получить буфер обмена

    Поиск: clipboard. В списке нажмите Get Clipboard. Менять в нём ничего не нужно.

  2. Get Dictionary from Input Получить словарь из

    Поиск: get dictionary. В списке будут два похожих, нажмите Get Dictionary from Input.

    В команде оно читается «Get dictionary from Clipboard». Если вместо Clipboard написано Input или другое, нажмите это синее слово и выберите Clipboard.

  3. Get Dictionary Value Получить значение словаря, все ключи

    Поиск: get dictionary. В списке нажмите Get Dictionary Value, у него оранжевая иконка-книжка. Оно встанет сразу под предыдущим.

    Нажмите в нём синее слово Value и выберите All Keys. Если последнее синее слово не Dictionary, нажмите его и выберите Dictionary. В команде должно читаться «Get All Keys in Dictionary». Это список названий альбомов.

    Не путайте с Get Variable (иконка «x»): оно здесь не подойдёт. Если добавилось оно, удалите его крестиком справа.

  4. Repeat with Each Повторить с каждым

    Поиск: repeat. В списке нажмите Repeat with Each, не просто Repeat.

    В команде появятся две строки: «Repeat with each item in Dictionary Value» и ниже End Repeat. Если синее слово другое, нажмите его и выберите Dictionary Value.

  5. Get Dictionary Value, второй раз

    Поиск: get dictionary, снова Get Dictionary Value. Оно встанет под End Repeat: перетащите его выше, между «Repeat with each…» и «End Repeat».

    Здесь синее слово Value оставьте. Нажмите Key и выберите Repeat Item в строке над клавиатурой; если его там нет, нажмите Select Variable и коснитесь «Repeat with each…» над этим действием. У Repeat Item должен появиться значок серых стрелок: без значка это просто напечатанные буквы, и альбом выйдет пустым. Нажмите последнее синее слово и выберите Dictionary с оранжевой книжкой. В команде должно читаться «Get Value for Repeat Item in Dictionary».

  6. Repeat with Each, второй раз

    Поиск: repeat. В списке снова нажмите Repeat with Each. Он встанет в самый низ. Зажмите его верхнюю строку «Repeat with each…» и перетащите сразу под «Get Value for…»: блок переедет вместе со своим End Repeat.

    Нажмите бледное слово Items, затем Select Variable, и нажмите на действие «Get Value for Repeat Item in Dictionary» прямо над ним. В команде должно читаться «Repeat with each item in Dictionary Value».

  7. Find Photos Найти фото

    Поиск: find photos. В списке нажмите Find Photos и перетащите его внутрь второго повтора: под второй «Repeat with each…», выше его End Repeat. Оно сдвинется вправо дважды. Внутри повтора Shortcuts часто сам подставляет в него Repeat Item 2, и действие читается «Filter Repeat Item 2». Так оно ищет не в медиатеке и ничего не найдёт: нажмите плашку Repeat Item 2 под словом Filter и выберите Clear. Должно стать «Find Photos where». Фильтр Name при этом не удаляйте, Clear убирает только плашку.

    Нажмите Add Filter. Появится строка вроде «Album is Recents». Нажмите в ней Album и выберите Name. Нажмите слово is и выберите begins with: в «Фото» имя может храниться с расширением, вроде IMG_4520.HEIC, и точное совпадение его не находит. Нажмите поле справа и выберите Repeat Item 2, именно с двойкой и со значком стрелок, не печатайте. В команде должно читаться «Find Photos where Name begins with Repeat Item 2». Sort by и Limit можно не трогать; если Limit включён с Get 1 Item, это тоже работает.

  8. Create Photo Album Создать фотоальбом

    Поиск: album. В списке нажмите Create Photo Album. Оно встанет в самый низ: перетащите его между двумя End Repeat, то есть под End Repeat второго повтора и выше самого последнего End Repeat.

    Нажмите синее поле с именем альбома и выберите Repeat Item, без двойки и со значком стрелок, не печатайте. Нажмите синее поле с фото и выберите Repeat Results.

Нажмите Done справа вверху. Проверьте, что получилось так, отступ с чертой значит «внутри повтора»:

Get Clipboard
Get dictionary from Clipboard
Get All Keys in Dictionary
Repeat with each item in Dictionary Value
Get Value for Repeat Item in Dictionary
Repeat with each item in Dictionary Value
Find Photos where Name begins with Repeat Item 2
End Repeat
Create photo album Repeat Item with Repeat Results
End Repeat

Если какого-то действия или слова Name нет в списке, пришлите в чат снимок экрана, подберу замену.

Потом здесь нажмите «Сначала проверить команду на одном снимке» и разрешите команде доступ к буферу обмена и к «Фото». Если в «Фото» появился альбом «Проверка По полочкам» с одним снимком, всё собрано верно: удалите его и нажмите «Разложить по альбомам в «Фото»».

Вторая команда: докладывать в альбомы, которые уже есть

Нужна, чтобы новые снимки ложились в уже созданные «Сортировка: …», а не во вторые альбомы с тем же названием. Это копия первой команды, в которой поменяно одно действие. Первую команду не трогайте.

  1. В Shortcuts на вкладке Shortcuts нажмите и подержите плитку «По полочкам», выберите Duplicate. Появится копия «По полочкам 1».
  2. Нажмите и подержите копию, выберите Rename, впишите По полочкам добавить и нажмите Done.
  3. Откройте копию кнопкой ⋯ в углу плитки. На саму плитку не нажимайте: команда запустится.
  4. Удалите действие «Create photo album Repeat Item with Repeat Results» крестиком справа.
  5. В поиске внизу наберите save to photo и нажмите Save to Photo Album. Оно встанет в самый низ: перетащите его на место удалённого, между двумя End Repeat.
  6. В нём нажмите первую синюю плашку, выберите Clear, нажмите пустое поле, затем Select Variable и коснитесь End Repeat прямо над этим действием. Появится Repeat Results.
  7. Нажмите Recents и выберите Repeat Item со значком стрелок; если его нет в списке, нажмите Select Variable и коснитесь самого верхнего «Repeat with each». Должно читаться «Save Repeat Results to Repeat Item».

Проверка: сначала нажмите «Сначала проверить команду на одном снимке», чтобы появился альбом «Проверка По полочкам», потом «Потом проверить, что вторая команда докладывает в альбом». В альбоме должно стать два снимка, а в «Недавних» не должно появиться копий.

Третья команда: убирать снимки из альбома, откуда их брали

Нужна, только если вписываете выше альбом, из которого брали снимки. Это ещё одна копия, в которой поменяно одно действие.

  1. Нажмите и подержите плитку «По полочкам добавить», выберите Duplicate, затем у копии Rename: По полочкам убрать.
  2. Откройте копию кнопкой ⋯ и удалите действие «Save Repeat Results to Repeat Item» крестиком справа.
  3. В поиске наберите remove from album и нажмите Remove from Album (иконка «Фото»; не Delete Photos). Перетащите его на место удалённого, между двумя End Repeat.
  4. Первую синюю плашку: Clear, затем Select Variable и End Repeat прямо над действием, появится Repeat Results. Альбом: Repeat Item со значком стрелок. Должно читаться «Remove Repeat Results from Repeat Item».

Проверка: после двух проверок выше нажмите «И что третья убирает снимок из альбома». В «Проверка По полочкам» останется один снимок, а убранный должен остаться в Recents.

Снимки ищутся по имени файла: у снимков с камеры это IMG_4184, у сохранённых из приложений бывают имена вроде camphoto_33463914 или длинный набор букв и цифр. Имя видно в «Фото», если открыть снимок и смахнуть вверх. Отредактированные фото приходят с именем FullSizeRender, их команда не найдёт. Если в галерее несколько снимков с одним именем (после IMG_9999 счёт идёт заново), в альбом попадут все они. Сайт помнит, какие альбомы уже создал, и в них докладывает второй командой. Если удалили альбом в «Фото», снимите с него галочку, и он создастся заново. Переименовать сами снимки в «Фото» нельзя: имена вида «2026-07-23 Пятигорск, Белка» есть только у копий в архиве.
