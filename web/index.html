По полочкам

Фото разбираются прямо на телефоне и никуда не отправляются.

Выберите фото, и приложение разложит их по категориям: внутри от новых к старым, с именем вида «2026-07-23 Пятигорск, Белка». Текст на фото оно прочитает и определит его тему.

Модели: OpenCLIP (MIT), EmbeddingGemma (Gemma Terms of Use), Tesseract (Apache 2.0). Города: GeoNames, CC BY 4.0.

Как выбрать сразу весь альбом

В окне выбора. Нажмите «Выбрать фото», затем «Медиатека», откройте «Альбомы» и нужный альбом. Чтобы не нажимать на каждый снимок, проведите пальцем по миниатюрам, не отрывая его: отметятся все, по которым он прошёл.

Весь альбом одной кнопкой.

  1. В приложении «Фото» откройте альбом, нажмите «Выбрать», затем «Выбрать все».
  2. Нажмите «Поделиться», затем «Сохранить в Файлы» и выберите или создайте папку.
  3. Здесь нажмите «Выбрать фото», затем «Выбрать файлы», откройте эту папку, нажмите «Выбрать», затем «Выбрать все» и «Открыть».

Те же фото второй раз не добавятся, так что альбом можно докладывать частями.

Альбомы в «Фото». Команда на iPhone создаст по альбому «Сортировка: …» на каждую категорию и добавит в него эти же снимки из вашей галереи, без копий. Перед первым разом один раз соберите команду по шагам ниже.

Как один раз настроить команду

Названия даны как на iPhone с английским языком. Займёт минут десять, потом команда просто запускается этой кнопкой.

Открыть новую команду в Shortcuts

Или сами: приложение Shortcuts, вкладка Library, «+» справа вверху.

Как работать в редакторе

  • Добавить действие. Внизу экрана поле Search Actions. Нажмите его, введите слово из шага ниже и нажмите в списке действие с точно таким названием, как жирное в шаге. Оно добавится в команду и дальше читается уже фразой, например Get Dictionary from Input становится «Get dictionary from Clipboard».
  • Переставить. Новое действие всегда встаёт в самый низ. Зажмите его за название и, не отпуская, тяните вверх на нужное место. Всё, что внутри повтора, сдвинуто вправо.
  • Синие слова в действии можно менять. Нажмите синее слово: появится список или строка над клавиатурой с вариантами вроде Repeat Item. Нажмите нужный. Если его там нет, нажмите Select Variable и найдите его там.
  • Ошиблись с синим словом: нажмите его ещё раз и выберите заново.

Важно: Repeat Item, Repeat Item 2, Repeat Results, Dictionary, Dictionary Value и Clipboard нужно выбирать из списка, а не печатать буквами. Выбранное выглядит как плашка со значком: у Repeat Item и Repeat Results это серые стрелки повтора, у Dictionary оранжевая книжка. Если слова просто напечатаны, без значка, команда создаст пустой альбом с именем «Repeat Item». Тогда нажмите это поле, сотрите текст и выберите вариант в строке над клавиатурой или через Select Variable.

Имя команды

Нажмите New Shortcut вверху по центру, затем Rename, введите По полочкам и нажмите Done на клавиатуре.

Семь действий по порядку

  1. Get Clipboard Получить буфер обмена

    Поиск: clipboard. В списке нажмите Get Clipboard. Менять в нём ничего не нужно.

  2. Get Dictionary from Input Получить словарь из

    Поиск: get dictionary. В списке будут два похожих, нажмите Get Dictionary from Input. Второе, Get Dictionary Value, понадобится позже.

    В команде оно читается «Get dictionary from Clipboard». Если вместо Clipboard написано Input или другое, нажмите это синее слово и выберите Clipboard.

  3. Repeat with Each Повторить с каждым

    Поиск: repeat. В списке нажмите Repeat with Each, не просто Repeat.

    В команде появятся две строки: «Repeat with each item in Dictionary» и ниже End Repeat. Если синее слово не Dictionary, нажмите его и выберите Dictionary.

  4. Get Dictionary Value Получить значение словаря

    Поиск: get dictionary. В списке нажмите Get Dictionary Value, у него оранжевая иконка-книжка, как у шага 2. Оно встанет под End Repeat: перетащите его выше, между «Repeat with each…» и «End Repeat».

    Не путайте с Get Variable (иконка «x», в команде читается «Get Variable»): оно здесь не подойдёт. Если добавилось оно, удалите его крестиком справа и добавьте Get Dictionary Value.

    Теперь синие слова. Нажмите Key и выберите Repeat Item. Нажмите последнее синее слово и выберите Dictionary. В команде должно читаться «Get Value for Repeat Item in Dictionary».

  5. Repeat with Each, второй раз

    Поиск: repeat. В списке снова нажмите Repeat with Each. Он встанет в самый низ. Зажмите его верхнюю строку «Repeat with each…» и перетащите сразу под Get Dictionary Value: блок переедет вместе со своим End Repeat.

    Сначала там бледное слово Items: нажмите его и выберите Dictionary Value. В команде должно читаться «Repeat with each item in Dictionary Value». Если оставить Items, команда не найдёт ни одного фото.

  6. Find Photos Найти фото

    Поиск: find photos. В списке нажмите Find Photos и перетащите его внутрь второго повтора: под второй «Repeat with each…», выше его End Repeat. Оно сдвинется вправо дважды.

    Нажмите Add Filter. Появится строка вроде «Album is Recents». Нажмите в ней Album и выберите Name. Слово is оставьте. Нажмите поле справа от is и выберите Repeat Item 2, именно с двойкой и со значком стрелок, не печатайте. В команде должно читаться «Find Photos where Name is Repeat Item 2». Sort by и Limit можно не трогать; если Limit включён с Get 1 Item, это тоже работает.

  7. Create Photo Album Создать фотоальбом

    Поиск: album. В списке нажмите Create Photo Album. Оно встанет в самый низ: перетащите его между двумя End Repeat, то есть под End Repeat второго повтора и выше самого последнего End Repeat.

    Нажмите синее поле с именем альбома и выберите Repeat Item, без двойки и со значком стрелок, не печатайте. Нажмите синее поле с фото и выберите Repeat Results.

Нажмите Done справа вверху. Проверьте, что получилось так, отступ с чертой значит «внутри повтора»:

Get Clipboard
Get dictionary from Clipboard
Repeat with each item in Dictionary
Get Value for Repeat Item in Dictionary
Repeat with each item in Dictionary Value
Find Photos where Name is Repeat Item 2
End Repeat
Create photo album Repeat Item with Repeat Results
End Repeat

Если какого-то действия или слова Name нет в списке, пришлите в чат снимок экрана, подберу замену.

Потом здесь нажмите «Разложить по альбомам в «Фото»» и разрешите команде доступ к буферу обмена и к «Фото». Сначала попробуйте на нескольких снимках.

Снимки ищутся по имени файла вроде IMG_4184. Отредактированные фото приходят с именем FullSizeRender, их команда не найдёт. Если в галерее несколько снимков с одним именем (после IMG_9999 счёт идёт заново), в альбом попадут все они. Каждый запуск создаёт альбомы заново, поэтому старые «Сортировка: …» перед повтором лучше удалить. Переименовать сами снимки в «Фото» нельзя: имена вида «2026-07-23 Пятигорск, Белка» есть только у копий в архиве.
