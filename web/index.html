По полочкам

Фото разбираются прямо на телефоне и никуда не отправляются.

Выберите фото, и приложение разложит их по категориям: внутри от новых к старым, с именем вида «2026-07-23 Пятигорск, Белка». Текст на фото оно прочитает и определит его тему.

Как выбрать сразу весь альбом

В окне выбора. Нажмите «Выбрать фото», затем «Медиатека», откройте «Альбомы» и нужный альбом. Чтобы не нажимать на каждый снимок, проведите пальцем по миниатюрам, не отрывая его: отметятся все, по которым он прошёл.

Весь альбом одной кнопкой.

  1. В приложении «Фото» откройте альбом, нажмите «Выбрать», затем «Выбрать все».
  2. Нажмите «Поделиться», затем «Сохранить в Файлы» и выберите или создайте папку.
  3. Здесь нажмите «Выбрать фото», затем «Выбрать файлы», откройте эту папку, нажмите «Выбрать», затем «Выбрать все» и «Открыть».

Те же фото второй раз не добавятся, так что альбом можно докладывать частями.

Альбомы в «Фото». Команда на iPhone создаст по альбому «Сортировка: …» на каждую категорию и добавит в него эти же снимки из вашей галереи, без копий. Перед первым разом один раз соберите команду по шагам ниже.

Как один раз настроить команду

Названия действий даны как на iPhone с английским языком, рядом серым по-русски.

Открыть новую команду в Shortcuts
  1. Нажмите имя сверху (New Shortcut), затем Rename, и впишите По полочкам.
  2. В поиске внизу (Search Actions) найдите и добавьте Get Clipboard Получить буфер обмена.
  3. Get Dictionary from Input Получить словарь из. Получится «Get dictionary from Clipboard».
  4. Repeat with Each Повторить с каждым. Получится «Repeat with each item in Dictionary» и под ним End Repeat.
  5. Get Dictionary Value Получить значение словаря. Перетащите его между Repeat и End Repeat. Нажмите Key и выберите Repeat Item.
  6. Ещё один Repeat with Each. Перетащите его под Get Dictionary Value, тоже внутрь первого повтора. Он должен взять Dictionary Value.
  7. Find Photos Найти фото. Перетащите внутрь второго повтора. Нажмите Add Filter, затем Album и выберите Name, оставьте is, в поле значения выберите Repeat Item 2. Включите Limit и оставьте 1 Photo.
  8. Create Photo Album Создать фотоальбом. Перетащите между двумя End Repeat. Имя альбома: Repeat Item, фото: Repeat Results.

Должно получиться так, отступ с чертой значит «внутри повтора»:

Get Clipboard
Get dictionary from Clipboard
Repeat with each item in Dictionary
Get Value for Repeat Item in Dictionary
Repeat with each item in Dictionary Value
Find All Photos where Name is Repeat Item 2, Limit 1 Photo
End Repeat
Create photo album Repeat Item with Repeat Results
End Repeat

Новое действие встаёт в самый низ: зажмите его и перетащите на место. Переменную вроде Repeat Item выбирают в строке над клавиатурой или через Select Variable.

Потом здесь нажмите «Разложить по альбомам в «Фото»» и разрешите команде доступ к буферу обмена и к «Фото». Сначала попробуйте на нескольких снимках.

Снимки ищутся по имени файла вроде IMG_4184. Отредактированные фото приходят с именем FullSizeRender, их команда не найдёт. Каждый запуск создаёт альбомы заново, поэтому старые «Сортировка: …» перед повтором лучше удалить. Переименовать сами снимки в «Фото» нельзя: имена вида «2026-07-23 Пятигорск, Белка» есть только у копий в архиве.
